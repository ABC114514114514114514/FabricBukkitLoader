========================================
核心功能
========================================

1. ✅ Fabric Mod加载系统
   - 从服务器根目录/mods/加载Fabric mods
   - 支持.jar和.zip格式的mod文件
   - 自动解析fabric.mod.json元数据

2. ✅ 事件适配系统
   - 自动将Bukkit事件转换为Fabric事件格式
   - 支持玩家、方块、实体、库存等事件
   - 可配置的事件优先级和过滤

3. ✅ 命令适配系统
   - 支持Fabric mod命令在Paper服务器上运行
   - 自动注册mod定义的命令
   - 完整的权限控制

4. ✅ 配置管理系统
   - 灵活的配置文件(config.yml)
   - 支持热重载
   - 详细的日志记录选项

5. ✅ 安全控制系统
   - 白名单/黑名单机制
   - 插件签名验证（可选）
   - 权限节点管理

6. ✅ 管理命令
   - /fabricloader help - 帮助信息
   - /fabricloader info - 插件信息
   - /fabricloader mods - 查看mods
   - /fabricloader reload - 重载插件
   - /fabricloader load <mod> - 加载mod
   - /fabricloader unload <mod> - 卸载mod

========================================
安装和使用
========================================

【安装步骤】
1. 将 target/FabricBukkitLoader-1.1.0.jar 复制到Paper服务器的 plugins/ 文件夹
2. 启动服务器，插件会自动创建配置和目录
3. 在服务器根目录创建 mods/ 文件夹
4. 将Fabric mod的 .jar 文件放入 mods/ 文件夹
5. 重启服务器或使用 /fabricloader reload
6. 使用 /fabricloader mods 查看已加载的mods

【目录结构】
服务器根目录/
├── mods/                          ← 放Fabric mods
│   └── *.jar
├── plugins/                       ← Bukkit插件
│   ├── FabricBukkitLoader-1.1.0.jar
│   └── ...
├── plugins/FabricBukkitLoader/    ← 插件配置
│   ├── config.yml
│   └── libs/
└── ...

【常用命令】
/fabricloader help        - 显示帮助
/fabricloader info        - 显示插件信息
/fabricloader mods        - 查看已加载mods
/fabricloader reload      - 重载插件
/fabricloader update      - 检查mod更新
/fabricloader scan        - 扫描mod安全问题
/fabricloader perf report - 显示性能报告
/fblmods                  - 快速查看mods
